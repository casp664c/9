## Project summary

Kaninbanker is an Android-first Unity game designed for a phone-only development workflow. The repository is cloud-build-first: Unity Build Automation is intended to be the first real Unity Editor to import, compile and build the project.

## Confirmed environment

- Unity project root: repository root
- Target Unity generation: Unity 6
- Declared editor version: 6000.0.60f1
- Primary platform: Android
- Package manifest: minimal, no third-party runtime dependencies
- Render pipeline: Built-in / unresolved until first Unity import
- Input: legacy `UnityEngine.Input` API
- Networking: none
- Persistence: PlayerPrefs for high score, audio mute, internal/external music mode and last YouTube Music search

## Directory structure

- `Assets/Kaninbanker/Scripts/` - runtime gameplay, audio, YouTube Music companion and VFX feedback
- `Assets/Kaninbanker/Editor/` - cloud/editor bootstrap and Android build entry point
- `ProjectSettings/` - Unity version marker
- `Packages/` - minimal package manifest
- `Docs/` - build and integration documentation

## Scenes and startup

`Assets/Kaninbanker/Scenes/Main.unity` is generated by the editor bootstrap when missing. The bootstrap also writes the scene into Unity Build Settings. Runtime scene content is code-driven so no local PC scene authoring is required for the prototype.

## Architecture

- `KaninbankerGame` owns authoritative round state, scoring, combo logic, difficulty, input and procedural scene setup.
- `KaninbankerAudio` owns synthesized internal music/SFX, mute state and independent internal-music enablement.
- `KaninbankerExternalMusic` owns YouTube Music companion mode, last search and external/internal music selection.
- `KaninbankerMusicPanel` provides phone-friendly in-game music controls and opens the official YouTube Music experience.
- `KaninbankerFeedback` owns presentation-only pooled particles and camera shake.
- `RabbitHole` owns rabbit show/hide animation state.

## Current gameplay/presentation

- 3x3 rabbit holes
- procedural rabbit meshes assembled from Unity primitives
- touch/mouse whacking
- 30-second rounds
- score, high score, combo, hits, misses and accuracy
- increasing speed/difficulty through the round
- Android haptic vibration on successful hit
- pooled hit/miss particles and camera shake
- procedural rabbit pop/wobble animation
- synthesized bonk, combo, miss, rabbit-pop, round-start, game-over and UI sounds
- synthesized looping lightweight chiptune-style background music
- persistent sound toggle
- YouTube Music companion panel: search/open official YouTube Music, disable only internal soundtrack, preserve game SFX, restore internal music

## Android/cloud build behavior

The editor bootstrap configures:

- product name `Kaninbanker`
- application id `com.casp664c.kaninbanker`
- version `0.1.0`
- Android version code `1`
- minimum Android API level 26
- ARM64
- IL2CPP
- landscape orientation
- `PlayerSettings.muteOtherAudioSources = false` so compatible external music apps can continue alongside Kaninbanker SFX

Custom Android build entry point: `Kaninbanker.Editor.KaninbankerBuild.BuildAndroidApk`.

## YouTube Music integration rule

The project does not extract, download, proxy, isolate or secretly background-play YouTube audio. It opens the official YouTube Music service externally and lets Android/YouTube Music own playback. This avoids creating a hidden YouTube player and keeps the game independent of YouTube API credentials.
