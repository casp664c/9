## Scenes and startup

`Assets/Kaninbanker/Scenes/Main.unity` is generated by the editor bootstrap during import when missing. The bootstrap also writes the scene into Unity Build Settings.

## Architecture

The prototype uses one small runtime owner (`KaninbankerGame`) for round state, input, procedural scene presentation and HUD. This is deliberately simple for the first cloud-build proof. Rabbits and holes are lightweight MonoBehaviours created at runtime.
